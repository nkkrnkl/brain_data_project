# Developmental fMRI graph-metric pipeline

Final project for ECE 5260 / ORIE 5735, Cornell Tech.

## Summary

This repository contains the code, sweep artifacts, and figures behind an
analysis of how undirected weighted functional-connectivity graph
structure changes with age in the Richardson et al. 2018 developmental
fMRI cohort (155 subjects listed; 131 with preprocessed BOLD available
in GS bucket `gs://results_050626/`). The pipeline parcellates each 4D BOLD run
with Schaefer-100 (MNI), regresses Friston-24 + WM + CSF + DCT after
FD scrubbing, builds top-κ thresholded graphs from Fisher-z correlation
matrices, and tests OLS `metric ~ age + sex + mean_FD` over a five-metric
panel (clustering Onnela, modularity Q, characteristic path L,
small-worldness σ, mean betweenness) with FDR across the panel. The
primary cell is FD=0.5, κ=0.10; κ and FD sweeps are sensitivity analyses.

## How to reproduce

### Setup

```bash
gcloud auth application-default login
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### Smoke test (~10s)

```bash
python3 smoke_test.py
```

### Full pipeline

```bash
python3 sweep_driver.py all
python3 compute_metrics.py all
./run_finish.sh
python3 make_pipeline_figure.py
```

### Supplementary Fix A

```bash
python3 supplement_fixA_build_nobump.py --fd 0.5 --kappa 0.10
python3 compute_metrics_nobump_lcc.py --fd 0.5 --kappa 0.10
python3 analyze_age_nobump_lcc.py --fd 0.5 --kappa 0.10
```

Total compute on a cold cache: ~90 minutes; ~100 MB on-disk cache;
~3 MB tracked outputs in `results/`.

## Dependencies

- All Python packages listed in `requirements.txt`.
- External data: Google Cloud Storage bucket `gs://results_050626/`
  (project `brain-data-project-050626`). The bucket contains all data
  for this project; access upon request. Reads use Application Default
  Credentials (`gcloud auth application-default login`); `gcs_loader.py`
  streams via `gcsfs`. Do not pass `project=` to `gcsfs.GCSFileSystem` —
  it will fail when your ADC default project differs from the bucket's.
